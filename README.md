# বগুড়া ডিবেটিং সোসাইটি — অফিসিয়াল ওয়েবসাইট

Next.js 15 (App Router) + Tailwind CSS v4 দিয়ে তৈরি, **সম্পূর্ণ static** ওয়েবসাইট।
কোনো সার্ভার লাগে না — Netlify-র ফ্রি প্ল্যানেই চলবে।

সব কনটেন্ট (১৯টি অনুশীলনী বিতর্ক, ২৫টি motion, ১৭টি Campus Connect stop, ৭টি আয়োজন,
টিম, অংশীদার) আসল আর্কাইভ থেকে নেওয়া এবং `src/content/` ফোল্ডারে টাইপ-করা ফাইলে আছে।

---

## ১. Netlify-তে লাইভ করা — দুইটা পথ

### ▸ পথ ক — সবচেয়ে সহজ (Drag & Drop, ৩ মিনিট)

```bash
npm install
npm run build
```

এতে একটা **`out/`** ফোল্ডার তৈরি হবে।

1. https://app.netlify.com/drop খোলো
2. **`out` ফোল্ডারটা** পুরোটা টেনে ব্রাউজারে ছেড়ে দাও
3. ব্যস — সাইট লাইভ। একটা ফ্রি ঠিকানা পাবে, যেমন `random-name-123.netlify.app`
4. Site settings → **Change site name** → `bogura-debating-society` লিখলে ঠিকানা হবে
   `bogura-debating-society.netlify.app`

> ⚠ **`out` ফোল্ডারই আপলোড করতে হবে** — পুরো প্রজেক্ট ফোল্ডার নয়।

### ▸ পথ খ — GitHub-এর সাথে যুক্ত করে (একবার সেট করলে পরে শুধু push)

1. GitHub-এ একটা নতুন repository বানাও
2. এই ফোল্ডার থেকে:
   ```bash
   git init
   git add .
   git commit -m "BDS website"
   git branch -M main
   git remote add origin https://github.com/<তোমার-ইউজারনেম>/<repo>.git
   git push -u origin main
   ```
3. Netlify → **Add new site → Import an existing project** → GitHub → repo বেছে নাও
4. Build settings এমনিতেই ঠিক থাকবে (`netlify.toml` ফাইলে লেখা আছে):
   - Build command: `npm run build`
   - Publish directory: `out`
5. Deploy চাপো।

এরপর যখনই GitHub-এ push করবে, Netlify নিজে থেকে নতুন version লাইভ করে দেবে।

### ▸ নিজের ডোমেইন যোগ করা

Netlify → Domain settings → **Add custom domain**।

⚠ **একটা জরুরি কথা:** এখন যে ডোমেইন আছে — `boguradebatingsocity.com` — সেখানে
"society" বানানে **e** নেই। সঠিক বানানের `boguradebatingsociety.com` কিনে সেটাকে
প্রধান (canonical) ডোমেইন করা উচিত, আর পুরোনোটা 301 redirect দিয়ে দাও।
`src/content/site.ts`-এর `domain` ফিল্ডেও সঠিক ঠিকানাটা বসিয়ে দিও (sitemap ও SEO
ট্যাগ ওখান থেকেই তৈরি হয়)।

## ২. ছবি বসানো (সবচেয়ে জরুরি কাজ)

এখন সব ছবির জায়গায় ব্র্যান্ড-রঙের placeholder দেখাচ্ছে — সাইট ভাঙেনি, শুধু ছবি নেই।
নিচের নামে ছবি রেখে আবার `npm run build` দিলেই ছবিগুলো বসে যাবে। **কোনো কোড বদলাতে হবে না।**

```
public/images/
├── hero/
│   ├── main.jpg        ← হোমপেজের মূল ছবি (তর্ক তরঙ্গ ২৬-এর মঞ্চ হলে সবচেয়ে ভালো)
│   ├── thumb-1.jpg     ← hover করলে যেগুলো ছিটকে বেরোয় (তর্ক তরঙ্গ ২৬)
│   ├── thumb-2.jpg     ← Beyond Words
│   ├── thumb-3.jpg     ← আজিজুল হক কলেজ কর্মশালা
│   ├── thumb-4.jpg     ← বিজয় দিবস বারোয়ারি
│   └── thumb-5.jpg     ← দুপচাঁচিয়া কর্মশালা
└── team/
    └── leader.jpg      ← হোমপেজের "সংগঠনের ভাবনা" অংশের ছবি
```

**ছবির মাপ:** hero-র মূল ছবি ~১৬০০×১৪৩০ px, বাকিগুলো ~১২০০×৯০০ px।
JPG-ই যথেষ্ট, প্রতিটা ৩০০ KB-র নিচে রাখলে সাইট দ্রুত লোড হবে
([squoosh.app](https://squoosh.app) দিয়ে সহজে কমানো যায়)।

**টিমের সদস্যের ছবি:** `public/images/team/<নাম>.jpg` রেখে
`src/content/people.ts`-এ ওই ব্যক্তির `photo: '/images/team/<নাম>.jpg'` লিখে দাও।
ছবি না থাকলে নামের আদ্যক্ষর দিয়ে সুন্দর avatar দেখাবে।

**লোগো:** তোমাদের আসল লোগো বসানো হয়ে গেছে —
`public/brand/logo-light.png` (কালো, হালকা ব্যাকগ্রাউন্ডের জন্য),
`logo-dark.png` (সাদা, ডার্ক মোডের জন্য) এবং `mark.png` (শুধু জেলার মানচিত্র,
favicon হিসেবে ব্যবহৃত)। তিনটাই transparent background-সহ।

## ৩. Form সংযুক্ত করা (Netlify Forms — একদম ফ্রি)

`join` ও `contact` ফর্ম দুটো **Netlify Forms**-এর জন্য আগেই তৈরি করা আছে
(`data-netlify="true"` + honeypot বসানো)। Netlify-তে deploy করার পর:

1. Netlify dashboard → **Forms** ট্যাব
2. `bds-join` আর `bds-contact` — দুটো ফর্ম নিজে থেকেই দেখা যাবে
3. Forms → **Form notifications** → *Email notification* যোগ করে
   `boguradebatingsociety@gmail.com` দাও — কেউ ফর্ম পূরণ করলেই মেইল আসবে

ফ্রি প্ল্যানে মাসে ১০০টি submission পাওয়া যায়। বেশি লাগলে Google Form-এ
রিডাইরেক্ট করাও একটা সহজ বিকল্প।

সব ঠিকঠাক কাজ করলে `src/content/dict.ts`-এ `join.formNote` লেখাটা মুছে দিও
(এখন ওখানে "ফর্ম এখনো সার্ভারে যুক্ত নয়" লেখা আছে)।

## ৪. কনটেন্ট বদলানো

সব লেখা **`src/content/`** ফোল্ডারে। কোনো component ফাইল ছুঁতে হবে না।

| ফাইল | কী আছে |
|---|---|
| `site.ts` | নাম, স্লোগান, ঠিকানা, ফোন, ইমেইল, সব সংখ্যা, বিতর্কের ধরন |
| `dict.ts` | সব বাংলা ও ইংরেজি UI লেখা (মেনু, বোতাম, শিরোনাম) |
| `motions.ts` | Motion Bank-এর ২৫টি motion |
| `practiceDebates.ts` | ১৯টি অনুশীলনী বিতর্ক + সক্রিয় বিতার্কিকদের নাম |
| `events.ts` | ৭টি বড় আয়োজনের পূর্ণ তথ্য |
| `campus.ts` | Campus Connect-এর ১৭টি stop ও কর্মশালার কাঠামো |
| `people.ts` | উপদেষ্টা, মেন্টর, কার্যনির্বাহী কমিটি |
| `timeline.ts` | টাইমলাইন, অংশীদার তালিকা, সহায়ক widget-এর FAQ |

**নতুন motion যোগ করতে** — `motions.ts`-এ শেষে একটা লাইন:
```ts
{ id: 'pd-20', format: 'সনাতনী', topic: 'শিক্ষা',
  usedIn: '২০তম অনুশীলনী বিতর্ক', usedInEn: '20th Practice Debate',
  text: 'এখানে motion লেখো' },
```

**নতুন অনুশীলনী বিতর্ক যোগ করতে** — `practiceDebates.ts`-এ নতুন object।
শ্রেষ্ঠ বক্তাদের পাতা নিজে থেকেই আপডেট হয়ে যাবে।

## ৬. যেসব সিদ্ধান্ত ইচ্ছাকৃতভাবে নেওয়া হয়েছে

- **বহিষ্কৃত সদস্যের নাম সাইটে নেই।** ফেসবুক পোস্ট কিছুদিনে হারিয়ে যায়,
  কিন্তু ওয়েবসাইটের পাতা একজন তরুণের নাম চিরকালের জন্য সার্চ-ইঞ্জিনে বেঁধে দেয়।
  টিম পাতা থেকে নাম বাদ দেওয়াই যথেষ্ট বলে ধরা হয়েছে।
- **নেতৃত্ব পরিবর্তনের ভাষা নিরপেক্ষ** — "সাংগঠনিক পুনর্গঠন", "নতুন কার্যনির্বাহী
  নেতৃত্ব"। ইতিহাস লুকানো হয়নি, কিন্তু কারও দিকে আঙুল তোলাও হয়নি।
- **রাজনৈতিক শোকবার্তা সাইটে নেই** — সেগুলো ফেসবুকেই থাক। ওয়েবসাইটে স্থায়ী
  করলে সংগঠনের একটা রাজনৈতিক পরিচয় তৈরি হয়ে যায়।
- **সরকারি সংস্থার (দুদক, স্বরাষ্ট্র মন্ত্রণালয়) লোগো ব্যবহার করা হয়নি** এবং
  তাঁদের "partner" না লিখে "সহযোগিতায় কাজ করেছি" লেখা হয়েছে।
- **১৪তম সেশনের অনুপস্থিত রেকর্ড লুকানো হয়নি** — টেবিলে "রেকর্ড অনুপস্থিত"
  লেখা আছে। আর্কাইভের সততা এটাই।

এগুলোর কোনোটা বদলাতে চাইলে সংশ্লিষ্ট `src/content/` ফাইলে বদলে নিতে পারো।

## ৮. প্রযুক্তিগত নোট

- **সব animation pure CSS** — framer-motion / GSAP / AOS কিছুই নেই।
  Scroll reveal-এর জন্য native `animation-timeline: view()` ব্যবহার করা হয়েছে;
  যে ব্রাউজার সেটা বোঝে না, সেখানে সাধারণ fade-up fallback চলে।
- **`prefers-reduced-motion`** সম্পূর্ণভাবে মানা হয় — কারও ডিভাইসে animation
  বন্ধ থাকলে সাইটে কোনো নড়াচড়া হবে না।
- **ডার্ক মোড** `localStorage['bds-theme']`-এ থাকে, `<head>`-এর inline script
  পেজ আঁকার আগেই ক্লাস বসিয়ে দেয় — তাই সাদা ঝলকানি (FOUC) হয় না।
- **দুইটা ভাষা** আলাদা route-এ: `/bn/...` ও `/en/...`। ভাষা বদলালে একই পাতাতেই
  থাকা যায়।
- **SEO**: sitemap.xml, robots.txt, Open Graph, Twitter card এবং JSON-LD
  `Organization` schema — সবই তৈরি হয়।
- **ব্যাকগ্রাউন্ডের চারটা স্কেচ** (`public/patterns/`) হাতে-আঁকা SVG line-art।
  এগুলোই সাইটের নিজস্ব চেহারা তৈরি করে — বদলাতে চাইলে একই নামে নতুন SVG রাখো।
